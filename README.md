### 🎮 Game Development

My main solo project is **Grow My Island** — a Roblox simulation where the player develops an island while residents live increasingly autonomous lives around them.

Some of the systems I'm designing include:

- Grid-based island building and expansion
- Resident spawning, housing, and autonomy
- Personality and archetype systems
- Relationships and social behavior
- Requests, rewards, and progression
- Persistent saving/loading
- Building, decoration, and path systems
- Social visiting and island tours

I care a lot about keeping these systems **modular enough to grow without turning the codebase into spaghetti**.

### ⚙️ How I Like to Build

```text
Understand the real workflow
        ↓
Find the repetitive / unreliable part
        ↓
Build the smallest reliable system around it
        ↓
Add validation, observability, and failure handling
        ↓
Iterate from real usage
```

I like AI where it is useful, but I don't treat model output as truth. For production systems, I prefer pairing AI with **deterministic checks, clear gates, and software that fails visibly instead of silently**.
